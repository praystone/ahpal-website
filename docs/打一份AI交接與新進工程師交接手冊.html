10. 常見問題排錯

❌ Gemini API 429 Too Many Requests

解決方法
python src/main.py --force deepseek

❌ Cloudflare Pages 部署失敗（413 Payload Too Large）

原因

單一檔案超過 25 MiB 限制。

解決方法
  • 影音檔案上傳至 YouTube，不存放於 Pages
  • 檢查 videos/ 目錄是否有大型檔案

❌ Google Drive 備份失敗

解決方法
.\scripts\sync-to-gdrive.ps1 -Task videos

使用 Rclone 統一同步工具，繞過虛擬磁碟限制。

❌ 死命令檢查失敗

解決方法
.\scripts\preflight-check.ps1 -Fix

自動修復可修復的問題（如檔案過小、缺少品牌名稱等）。

❌ BFG Repo-Cleaner 清理 Git 歷史

用途

清理 Git 歷史中的大檔案或敏感檔案（已用於清除 114.84 MB 的 .pack 檔案）。

指令
java -jar C:\tools\bfg.jar --strip-blobs-bigger-than 100M --no-blob-protection
前置條件
  • 已安裝 Java（Eclipse Temurin 21）
  • BFG Jar 檔案位於 C:\tools\bfg.jar
  • 執行後需執行 git reflog expire --expire=now --all 與 git gc --prune=now --aggressive

14.2 影音檔案存放策略

決策內容
問題Cloudflare Pages 單一檔案限制 25 MiB
決策影音檔案不存放於 Pages，改為 YouTube + AI 檔案館 + Google Drive
📌 戰略原則
  • Pages 只放靜態檔案：HTML、CSS、JS、圖片（< 25MB）
