3. 🔧 筆電重點設定

3.1 電源與喚醒設定

# 一鍵設定 (系統管理員 PowerShell) # 1. 關閉喚醒登入鎖定 (執行期間無需 PIN) powercfg /SETACVALUEINDEX SCHEME_CURRENT SUB_NONE CONSOLELOCK 0 powercfg /SETDCVALUEINDEX SCHEME_CURRENT SUB_NONE CONSOLELOCK 0 # 2. 啟用喚醒計時器 (RTC) powercfg /SETACVALUEINDEX SCHEME_CURRENT SUB_SLEEP RTCWAKE 1 powercfg /SETDCVALUEINDEX SCHEME_CURRENT SUB_SLEEP RTCWAKE 1 # 3. 關閉快速啟動 (避免假關機) Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Power' -Name 'HiberbootEnabled' -Value 0 # 4. 開啟休眠功能 (支援 Shutdown /h) powercfg /hibernate on # 5. 套用 powercfg /SETACTIVE SCHEME_CURRENT

3.2 硬體喚醒衝突 (Thunderbolt/USB)

# 停用 Thunderbolt 喚醒 (Dell 筆電常見問題) powercfg /devicedisablewake "Thunderbolt(TM) Controller - 9A1B (001)" # 停用所有 USB/滑鼠喚醒 powercfg /devicequery wake_armed | ForEach-Object { powercfg /devicedisablewake "$_" } # 驗證 (應顯示「無」) powercfg /devicequery wake_armed

3.3 排程任務 (SYSTEM 帳戶，背景執行)

# 建立 SYSTEM 帳戶排程 (無需 PIN，背景執行) $RunTime = (Get-Date).AddMinutes(3) $Trigger = New-ScheduledTaskTrigger -Once -At $RunTime $Action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoProfile -ExecutionPolicy Bypass -File `"C:\Users\User\ahpal-static\scripts\auto-nature-batch.ps1`"" $Principal = New-ScheduledTaskPrincipal -UserId "SYSTEM" -LogonType ServiceAccount -RunLevel Highest $Settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -WakeToRun -DontStopIfGoingOnBatteries -StartWhenAvailable -ExecutionTimeLimit (New-TimeSpan -Hours 4) Register-ScheduledTask -TaskName "AHPAL_Nature_Batch" -Action $Action -Trigger $Trigger -Principal $Principal -Settings $Settings -Force
