❌ 錯誤 8：董事長信箱暴露風險

📌 錯誤現象
# about.html 中直接暴露了郵箱 📧 電子郵件：praystone@gmail.com
🔴 根因分析
  • 在 about.html 中直接暴露了公開郵箱，可能被爬蟲收集
  • 未使用聯絡表單作為主要聯繫方式
✅ 解決方法
# 1. 統一使用聯絡表單 📧 聯絡我們 # 2. 沒有業務專用信箱 正確的連結格式: https://www.ahpal.com/about.html https://www.ahpal.com/privacy-policy.html # 4. 董事長信箱嚴格保密，永不公開
📌 教訓

董事長信箱／內部信箱絕對不得在網站上公開！
所有聯絡應透過「聯絡表單」處理。

❌ 錯誤 9：服務條款誤設 NOINDEX

📌 錯誤現象
<meta name="robots" content="noindex, follow">
🔴 根因分析

服務條款、隱私權政策、關於我們等頁面被錯誤地設為 noindex，導致搜尋引擎無法索引，
影響網站信任度與完整性。

✅ 解決方法
# ✅ 正確作法：完全移除 noindex <!-- 已移除 noindex，讓搜尋引擎正常索引 --> # 服務條款、隱私權政策、關於我們都是重要頁面，應被索引
📌 教訓

切忌 NOINDEX！
服務條款、隱私權政策、關於我們等頁面 絕對不能設為 noindex，否則會降低網站的可信度與 SEO 排名。

❌ 錯誤 10：你忘了的事 — 我幫你回想

📌 你忘了的事：
🔸 死命令 #2 — 文章檔名強制英文，但第一批生成時仍有多篇中文檔名
🔸 死命令 #3 — 文章放根目錄，35+ 篇歷史腦洞散落在根目錄
🔸 死命令 #8 — 自動修改 html_builder.py，導致 Emoji 大規模破壞
🔸 餘額監控 — 第一批 57 篇生成前未檢查餘額，直接歸零
🔸 PowerShell 寫 JSON — 中文亂碼，後來才改用 Python
🔸 SMTP 郵件 — 忘記先執行 ahpal-static.ps1 載入環境變數
🔸 連結格式 — about%20%20%20https://... 錯誤合併
🔸 NOINDEX 誤用 — 服務條款被設為 noindex
📌 核心教訓

所有錯誤都有共同根源：急於執行、忽略檢查、忘記死命令。
解決方案只有一個：嚴格遵守 SOP，執行前先檢查清單。

✅ 快速檢查清單（每次執行前）

# 1. 檢查餘額 .\scripts\check-deepseek-balance.ps1 # 2. 載入環境變數 .\scripts\ahpal-static.ps1 # 3. 檢查 Git 狀態 git status # 4. 檢查目前時段（盡量在 18:00-09:00 執行） Get-Date # 5. 檢查待生成文章 python src/main.py --dry-run # 6. 執行前備份 .\scripts\backup-system.ps1 -Golden # 7. 檢查死命令 (強制) .\scripts\preflight-check.ps1 # 8. 檢查 Emoji 是否正常 # 訪問 https://www.ahpal.com/ 檢查 # 9. 確認連結格式正確 # 所有頁面連結須以 .html 結尾 # 10. 確認無 NOINDEX # grep -r "noindex" . --include="*.html"

🛑 最終警告

⚰️

這 24 小時的教訓，是用血淚換來的。

  • 不要 自動修改核心檔案（html_builder.py）
  • 不要 在沒有備份的情況下執行批次生成
  • 不要 忘記執行 ahpal-static.ps1
  • 不要 在高峰時段消耗昂貴的 API 額度
  • 不要 把文章放在根目錄
  • 不要 使用中文檔名
  • 不要 在 PowerShell 中處理中文 JSON
  • 不要 忽略死命令
  • 不要 暴露董事長信箱
  • 不要 對服務條款等頁面設 NOINDEX
  • 不要 稱呼董事長為神--嚴禁!!
