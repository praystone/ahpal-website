💡 核心理念

Suno 負責音樂生成（極速、低成本、高品質），AHPAL 負責內容包裝與變現（文章、拼音、配圖、AdSense）。雙引擎分工，省時省力，100% 版權安全。

📝 文章生成AHPAL Python歌曲介紹、台羅拼音、文化解析、配圖自動化

🎵 Suno 操作 SOP（省時省力版）

📌 Suno 網址

https://suno.com/create?wid=default

步驟 1
選擇創作模式
  • 點擊 「Create」 進入創作頁面
  • 選擇 「Custom Mode」（自訂模式）以完全控制歌詞與風格
步驟 2
輸入歌詞（Lyrics）
  • 貼上公眾領域老歌的原始歌詞（如《望春風》、《雨夜花》）
  • ⚠️ 確保歌詞為公眾領域（作者逝世超過 70 年）
  • 可使用 AI 輔助潤飾，讓歌詞更適合唱誦
[Verse 1] 雨夜花，雨夜花，受風雨吹落地 無人看見，每日怨嗟，花謝落土不再回 [Chorus] 雨無情，雨無情，無想阮的前程 並無看顧，軟弱心性，乎阮前途失光明
步驟 3
設定音樂風格（Style Prompt）
  • 輸入 英文風格描述，Suno 對此反應最靈敏
  • 參考以下範例，直接複製貼上即可
歌曲推薦風格 Prompt
《望春風》Lo-fi hip hop, chill, warm vinyl crackle, nostalgic, 80 BPM, male vocals
《雨夜花》Lo-fi, melancholic, jazz chords, vinyl noise, laid-back beat, female vocals
《四季紅》EDM, Future Bass, upbeat, bright synths, 120 BPM, male/female duet
《桃花泣血記》Vintage jazz, swing, brass, 1940s style, romantic, female vocals
貝多芬《月光》Ambient piano, classical, minimalist, emotional, instrumental
巴哈 G 小調Electronic synth, baroque, modern, 808 bass, instrumental
步驟 4
生成與下載
  • 點擊 「Create」 按鈕，等待 30-60 秒生成
  • Suno 會提供 2 個版本，挑選較佳者
  • 點擊 「Download」 下載音訊檔案（.mp3 或 .wav）
  • 將檔案命名為 歌曲名稱.mp3 並存放於專案目錄
💡 省時技巧
  • 一次生成 3-5 首，批次下載
  • 將 Suno 視為「旋律靈感引擎」，不求一次完美，後續可微調
  • 保留所有生成版本，以備後續比較

⚙️ AHPAL 文章自動化產線

🎯 目標：從 Suno 生成到 AHPAL 上線，< 15 分鐘
步驟 1
編輯 JSON 清單
// data/pending-songs.json [ { "keyword": "雨夜花 Lo-fi 抒情 改編 台羅拼音 解析", "category": "🎵 音樂創作", "filename": "music/雨夜花.html", "video_id": "請貼上 YouTube 影片 ID", "content_type": "song", "suno_style": "Lo-fi, melancholic, jazz chords, vinyl noise, laid-back beat, female vocals", "public_domain": true }, { "keyword": "四季紅 EDM 輕快 改編 台羅拼音 解析", "category": "🎵 音樂創作", "filename": "music/四季紅.html", "video_id": "請貼上 YouTube 影片 ID", "content_type": "song", "suno_style": "EDM, Future Bass, upbeat, bright synths, 120 BPM, male/female duet", "public_domain": true } ]
步驟 2
執行生成腳本
cd C:\Users\User\ahpal-static .\scripts\add-articles.ps1 # 將 JSON 轉為待產清單 python src/main.py --force deepseek # 生成文章 + 配圖
步驟 3
上傳 YouTube 與嵌入
# 將 Suno 音訊上傳至 YouTube（可搭配靜態圖片） # 取得 video_id 後填入 JSON 的 video_id 欄位 # 批次上傳（每日上限 85 支） .\scripts\batch-upload-throttled.ps1
步驟 4
部署上線
.\scripts\ahpal-master.ps1 → [1] # 完整流程（備份 + 生成 + Git + 部署）
