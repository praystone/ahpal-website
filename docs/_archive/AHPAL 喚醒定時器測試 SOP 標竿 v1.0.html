喚醒定時器測試標準作業程序 — 終極整合版
📌 版本 v2.0 · 2026 年 8 月 17 日
✅ 董事會核定 · 全員遵行

1. 目的

確保 AHPAL 系統在 螢幕關閉／系統睡眠 狀態下，工作排程器仍能 100% 準時喚醒 CPU 並執行預定任務，避免因 Windows Modern Standby (S0 低功耗閒置) 導致排程延遲或遺漏。

2. 適用情境

情境說明
🌙 晚間 19:00 歷史腦洞批次生成每日固定生成 100 篇文章
💾 凌晨備份任務每日凌晨自動備份系統
☁️ Cloudflare 部署任務生成完成後自動部署
⚙️ 任何無人值守排程需長時間關閉螢幕但須準時執行

3. 前置條件

項目條件
🖥️ 作業系統Windows 11 (22H2 以上)
🔑 權限系統管理員權限
🔌 電源建議插上 AC 電源 (確保喚醒定時器正常運作)
🔧 BIOS確認 BIOS 中 Wake on RTC / Wake on USB 已啟用

4. 標準作業步驟

步驟 0：🆕 新增文章前強制掃描目錄 (v2.0 核心)

⚠️ 血淚教訓： 2026-08-17 凌晨，因未掃描目錄，導致 100 篇主題與現有 167 篇文章高度重複，浪費時間與 API 成本。
從今以後，每次新增文章前必須執行此步驟。
  1. 切換至專案目錄 cd C:\Users\User\ahpal-static
  2. 掃描目標目錄現有檔案 (以 life/ 為例) ls life/*.html | ForEach-Object { $_.Name }
  3. 統計現有文章數量 (ls life/*.html).Count
  4. 從 master-articles.json 提取現有主題 python -c "import json; data=json.load(open('data/master-articles.json')); print('\n'.join([a['keyword'] for a in data if a.get('filename','').startswith('life/')]))"
  5. 比對新清單，過濾已存在主題 # 在 pending-articles.json 寫入前，先比對 master-articles.json
  6. 確認缺失數量 > 0 後才執行生成 if ($MissingArticles.Count -gt 0) { python src/main.py --force deepseek }
✅ 自動化掃描已整合： auto-life-batch.ps1 已在步驟 3 自動執行掃描與比對。
日誌中會顯示 📄 已存在: X 篇 與 ⚠️ 缺失 X 篇文章，請務必確認。

步驟 1：開啟喚醒定時器 (一次性設定)

以系統管理員身分執行 PowerShell，開啟系統喚醒定時器：

# ============================================================ # 步驟 1：開啟喚醒定時器 # ============================================================ # 1.1 開啟插電 (AC) 狀態下的喚醒定時器 powercfg -setacvalueindex SCHEME_CURRENT 238c9fa8-0aad-41ed-83f4-97be242c8f20 bd3b718a-0680-4d9d-8ab2-e1d2b4ac806d 1 # 1.2 開啟電池 (DC) 狀態下的喚醒定時器 powercfg -setdcvalueindex SCHEME_CURRENT 238c9fa8-0aad-41ed-83f4-97be242c8f20 bd3b718a-0680-4d9d-8ab2-e1d2b4ac806d 1 # 1.3 套用目前電源計畫 powercfg -setactive SCHEME_CURRENT Write-Host "✅ 喚醒定時器已開啟" -ForegroundColor Green

步驟 2：選擇執行模式 (🆕 v2.0 新增)

❌ 互動式任務 (Interactive)
  • 使用您的帳戶
  • LogonType: Interactive
  • ⚠️ 需要 PIN 碼
  • 視窗可見 (Normal)
  • 適合手動測試
✅ SYSTEM 任務 (ServiceAccount)
  • 使用 SYSTEM 帳戶
  • LogonType: ServiceAccount
  • ✅ 無需 PIN 碼
  • 視窗隱藏 (Hidden)
  • ✅ 適合正式排程

2.1 互動式任務 (含 PIN 碼驗證)

# ============================================================ # 步驟 2.1：註冊互動式排程任務 (需輸入 PIN 碼) # ============================================================ $Action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoProfile -ExecutionPolicy Bypass -WindowStyle Normal -File `"C:\Users\User\ahpal-static\scripts\target-script.ps1`"" $Trigger = New-ScheduledTaskTrigger -Once -At (Get-Date).AddMinutes(5) $Principal = New-ScheduledTaskPrincipal -UserId "$env:COMPUTERNAME\$env:USERNAME" -RunLevel Highest -LogonType Interactive $Settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -WakeToRun -DontStopIfGoingOnBatteries -StartWhenAvailable -Priority 4 Register-ScheduledTask -TaskName "AHPAL_Interactive_Task" -Action $Action -Trigger $Trigger -Principal $Principal -Settings $Settings -Force

2.2 🆕 SYSTEM 帳戶無人值守任務 (無需 PIN 碼)

# ============================================================ # 步驟 2.2：註冊 SYSTEM 帳戶無人值守任務 (無需 PIN 碼) # ============================================================ # ⭐ 關鍵：使用 SYSTEM 帳戶 + ServiceAccount $Principal = New-ScheduledTaskPrincipal -UserId "SYSTEM" -LogonType ServiceAccount -RunLevel Highest # 任務設定 (背景執行) $Action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File `"C:\Users\User\ahpal-static\scripts\target-script.ps1`"" $Settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -WakeToRun -DontStopIfGoingOnBatteries -StartWhenAvailable -Priority 4 Register-ScheduledTask -TaskName "AHPAL_System_Task" -Action $Action -Trigger $Trigger -Principal $Principal -Settings $Settings -Force Write-Host "✅ SYSTEM 帳戶無人值守任務已建立，無需 PIN 碼" -ForegroundColor Green

步驟 3：驗證喚醒計時器

# ============================================================ # 步驟 3：驗證喚醒計時器是否正常掛載 # ============================================================ # 3.1 顯示所有喚醒計時器 powercfg /waketimers # 3.2 檢查任務狀態 Get-ScheduledTask -TaskName "AHPAL_System_Task" | Format-List TaskName, State, Triggers
✅ 預期輸出範例：
[SERVICE] ... 設定的計時器在 HH:mm:ss 到期。
原因: Windows 將執行 'NT TASK\AHPAL_System_Task' 排定要求喚醒電腦的工作。

步驟 4：觸發睡眠測試

# ============================================================ # 步驟 4：觸發睡眠 (使用 C# 原生 API，確保喚醒計時器不受干擾) # ============================================================ # 4.1 關閉螢幕 (系統保持運作) $code = @" using System; using System.Runtime.InteropServices; public class Screen { [DllImport("user32.dll")] public static extern int SendMessage(int hWnd, int hMsg, int wParam, int lParam); } "@ Add-Type -TypeDefinition $code [Screen]::SendMessage(0xffff, 0x0112, 0xF170, 2) # 4.2 觸發睡眠 (不強制關閉，不禁用喚醒事件) $sleepCode = @" using System; using System.Runtime.InteropServices; public class Power { [DllImport("Powrprof.dll", SetLastError = true)] public static extern bool SetSuspendState(bool hibernate, bool forceCritical, bool disableWakeEvent); } "@ Add-Type -TypeDefinition $sleepCode [Power]::SetSuspendState($false, $false, $false) Write-Host "✅ 系統已進入睡眠，喚醒計時器將於指定時間觸發" -ForegroundColor Green

6. 🆕 完整驗證腳本 (v2.0 新增)

📌 使用方式： 複製下方腳本，在 PowerShell 中執行，自動檢查所有項目。
# ============================================================ # 🔍 AHPAL 排程驗證腳本 v2.0 # ============================================================ Write-Host "============================================================" -ForegroundColor Cyan Write-Host " 🔍 AHPAL 排程驗證工具 v2.0" -ForegroundColor Cyan Write-Host "============================================================" -ForegroundColor Cyan Write-Host "" $TaskName = "AHPAL_System_Task" $ScriptPath = "C:\Users\User\ahpal-static\scripts\auto-life-batch.ps1" $LogDir = "C:\Users\User\ahpal-static\logs" $PassCount = 0 $FailCount = 0 # 1. 檢查 RTC 喚醒 Write-Host "[1] RTC 喚醒狀態:" -ForegroundColor Yellow $wake = powercfg /waketimers | Select-String $TaskName if ($wake) { Write-Host " ✅ 已註冊" -ForegroundColor Green $PassCount++ } else { Write-Host " ❌ 未註冊" -ForegroundColor Red $FailCount++ } # 2. 檢查排程狀態 Write-Host "[2] 排程任務狀態:" -ForegroundColor Yellow $task = Get-ScheduledTask -TaskName $TaskName -ErrorAction SilentlyContinue if ($task -and $task.State -eq "Ready") { Write-Host " ✅ State: $($task.State)" -ForegroundColor Green $PassCount++ } elseif ($task) { Write-Host " ⚠️ State: $($task.State) (非 Ready)" -ForegroundColor Yellow $FailCount++ } else { Write-Host " ❌ 任務不存在" -ForegroundColor Red $FailCount++ } # 3. 檢查觸發時間 Write-Host "[3] 排程觸發時間:" -ForegroundColor Yellow if ($task -and $task.Triggers) { $trigger = $task.Triggers[0] if ($trigger.StartBoundary) { Write-Host " ✅ $($trigger.StartBoundary)" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 無觸發時間" -ForegroundColor Yellow $FailCount++ } } else { Write-Host " ❌ 無法讀取觸發時間" -ForegroundColor Red $FailCount++ } # 4. 檢查腳本存在 Write-Host "[4] 腳本存在:" -ForegroundColor Yellow if (Test-Path $ScriptPath) { Write-Host " ✅ 存在" -ForegroundColor Green $PassCount++ } else { Write-Host " ❌ 不存在" -ForegroundColor Red $FailCount++ } # 5. 檢查最新日誌 Write-Host "[5] 最新日誌:" -ForegroundColor Yellow $logs = Get-ChildItem "$LogDir\auto-life-batch-*.log" -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending if ($logs) { $latest = $logs[0] Write-Host " ✅ $($latest.Name) ($($latest.LastWriteTime))" -ForegroundColor Green $PassCount++ $content = Get-Content $latest -Raw # 檢查 API Key Write-Host "[6] API Key 已載入:" -ForegroundColor Yellow if ($content -match "✅ DEEPSEEK_API_KEY 已從 .env 載入") { Write-Host " ✅ 已載入" -ForegroundColor Green $PassCount++ } else { Write-Host " ❌ 未載入" -ForegroundColor Red $FailCount++ } # 檢查文章合併 Write-Host "[7] 文章合併成功:" -ForegroundColor Yellow if ($content -match "✅ 文章合併完成") { Write-Host " ✅ 成功" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 尚未合併" -ForegroundColor Yellow $FailCount++ } # 檢查文章生成 Write-Host "[8] 文章生成成功:" -ForegroundColor Yellow if ($content -match "✅ 文章生成完成") { Write-Host " ✅ 成功" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 尚未完成生成" -ForegroundColor Yellow $FailCount++ } # 檢查部署 Write-Host "[9] 部署成功:" -ForegroundColor Yellow if ($content -match "✅ 部署完成") { Write-Host " ✅ 成功" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 尚未部署" -ForegroundColor Yellow $FailCount++ } } else { Write-Host " ❌ 無日誌檔案" -ForegroundColor Red $FailCount++ } Write-Host "" Write-Host "============================================================" -ForegroundColor Cyan Write-Host " 📊 驗證結果：" -ForegroundColor Yellow Write-Host " ✅ 通過：$PassCount 項" -ForegroundColor Green Write-Host " ❌ 失敗：$FailCount 項" -ForegroundColor Red if ($FailCount -eq 0) { Write-Host " 🎉 全部通過！排程運作正常！" -ForegroundColor Green } else { Write-Host " ⚠️ 請檢查失敗項目並重新執行" -ForegroundColor Yellow } Write-Host "============================================================" -ForegroundColor Cyan

7. 疑難排解

問題可能原因解決方法
喚醒計時器未掛載 電源計畫未啟用 重複執行步驟 1
排程延遲執行 Modern Standby 介入 確保 -WakeToRun 與 Priority 4 已設定
需要輸入 PIN 碼 使用 Interactive 帳戶 改用 SYSTEM 帳戶 (ServiceAccount)
無 PowerShell 視窗 LogonType 為 S4U 改用 Interactive (測試用) 或 ServiceAccount (正式)
任務未執行 權限不足 確保 -RunLevel Highest
🆕 文章重複生成 未掃描目錄 執行步驟 0 強制掃描
