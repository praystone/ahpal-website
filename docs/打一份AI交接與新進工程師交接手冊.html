1. 系統概述

雅寶社區 · 頂客論壇 (AHPAL.COM) 是一個 AI 驅動的自動化內容平台，結合：

模組說明
🤖 AI 文章生成統一使用 DeepSeek Flash（成本僅 Pro 的 1/3）
🎮 HTML5 遊戲64 款互動遊戲，免下載即開即玩

⚙️ 自動化部署一鍵完成內容生成 → 靜態檔案輸出 → Cloudflare 部署
☁️ 雲端備份Rclone 自動同步至 Google Drive (ahpalke@gmail.com)

5. ⭐ 新增文章（JSON 驅動）

🎯 這是 AHPAL 內容營運的核心生產力工具

你不需要手動編輯 main.py！只要編輯 JSON，執行 MASTER，AI 就會自動為你生成文章。

步驟 1：編輯 data/pending-articles.json

[ { "keyword": "2026 年 MacBook Neo 購買指南", "category": "💻 3C 科技教學", "filename": "tech/macbook-neo-buying-guide-2026.html" }, { "keyword": "AI 生成圖片版權爭議與法律規範", "category": "🤖 AI 趨勢", "filename": "trend/ai-image-copyright-law-2026.html" } ]
📌 檔名規則

所有新文章必須使用英文檔名，避免編碼與 URL 亂碼問題。

  • ✅ 範例：macbook-neo-buying-guide-2026.html
  • ❌ 避免：2026年MacBook購買指南.html

步驟 2：執行 MASTER（自動處理）

cd C:\Users\User\ahpal-static .\scripts\ahpal-master.ps1 # 選擇 [1] 完整流程
