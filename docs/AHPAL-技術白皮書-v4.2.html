11. 🔋 RTC 喚醒技術整合 🆕 v4.2 新增

📌 技術背景： Windows 11 預設電源計劃會封鎖第三方排程的喚醒請求。AHPAL 系統透過 PowerShell + 工作排程器實現無人值守自動喚醒執行批次任務。

11.1 核心指令

# 解鎖 RTC 喚醒定時器 (一次性設定) powercfg /SETACVALUEINDEX SCHEME_CURRENT SUB_SLEEP RTCWAKE 1 powercfg /SETACTIVE SCHEME_CURRENT # 建立含喚醒設定的排程任務 $Settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -WakeToRun # 診斷指令 powercfg /waketimers

11.2 技術參數對照

參數技術層級說明
RTCWAKE 1電源層級啟用即時時鐘喚醒 (AC 電源)
-WakeToRun排程層級排程任務可喚醒系統執行
powercfg /waketimers診斷層級列出所有喚醒計時器
✅ 驗證通過標準： 執行 powercfg /waketimers 後，若輸出中能看到排程任務名稱及其預定執行時間，即代表硬體喚醒已完全就緒。
