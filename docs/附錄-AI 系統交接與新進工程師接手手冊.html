4.5 🚀 content_router 內容分流架構

📌 所有內容生成統一由 content_router.py 調度
  • 一般文章：→ article_generator.py
  • 音樂文章：→ song_generator.py（含 YouTube 嵌入）
  • 自動識別：根據 content_type 欄位自動分流
# content_router.py 核心邏輯 def generate_content(item): content_type = item.get("content_type", "article") if content_type == "song": return generate_song(item) # 🎵 音樂文章 else: return generate_article(item) # 📄 一般文章

7. 🎬 YouTube 影片嵌入系統

🎯 YouTube 影片自動嵌入流程
  • JSON 驅動：在 pending-songs.json 中填入 video_id
  • 自動嵌入：song_generator.py 自動生成 YouTube iframe
  • 置頂顯示：影片顯示在文章開頭（黃金 Header 下方）
  • 響應式設計：16:9 比例，適應所有裝置
# 音樂文章 JSON 範例 { "keyword": "望春風 Lo-fi 翻唱 解析", "category": "🎵 音樂創作", "filename": "music/bang-chhun-hong.html", "video_id": "A9Zw-QHEOqQ", "content_type": "song" } # 生成後自動嵌入 YouTube
