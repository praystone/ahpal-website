📌 死命令 #10 備忘錄：歷史腦洞文章生成規範

📌 生效日期： 2026-08-16
📌 適用範圍： 所有歷史腦洞文章的生成與新增作業

📋 規範內容

  1. 唯一入口： 歷史腦洞文章必須透過 auto-history-batch.ps1 批次生成。該腳本位於 C:\Users\User\ahpal-static\scripts\auto-history-batch.ps1。
  2. 禁止手動新增： 不得直接在 pending-articles.json 或 master-articles.json 中手動新增歷史腦洞文章。
  3. 禁止單獨生成： 不得使用 python src/main.py 單獨生成歷史腦洞文章（該方式僅適用於其他分類）。
  4. 文章清單維護： 所有歷史腦洞文章的主題清單必須定義於 auto-history-batch.ps1 中的 $Articles 陣列。

✅ 正確作法

# ✅ 正確：編輯 auto-history-batch.ps1 中的 $Articles 陣列 $Articles = @( @{ keyword = "新歷史腦洞主題"; filename = "new-article.html" }, # ... ) # ✅ 正確：執行 auto-history-batch.ps1 .\scripts\auto-history-batch.ps1

❌ 錯誤作法

# ❌ 錯誤：直接編輯 pending-articles.json # 手動加入歷史腦洞文章 → 禁止！ # ❌ 錯誤：使用 main.py 單獨生成歷史腦洞 python src/main.py --force deepseek # 僅適用於非歷史腦洞分類

⚠️ 例外處理

若因特殊情況需緊急新增單篇歷史腦洞文章，須經 董事長書面核准，並於下一次批次生成時補齊至 auto-history-batch.ps1 清單中。

📋 執行檢查清單 (手動)

建議每次執行歷史腦洞批次生成前，手動確認以下事項：

  • ☐ auto-history-batch.ps1 中的 $Articles 陣列已包含所有欲生成的主題
  • ☐ 所有 filename 皆為英文 (符合死命令 #2)
  • ☐ 所有主題皆標示分類為 📜 歷史腦洞
  • ☐ use_responses_api 與 enable_reasoning 皆設為 true
