3. 系統概述

雅寶社區 · 頂客論壇 (AHPAL.COM) 是一個 AI 驅動的自動化內容平台，結合：

模組說明
🤖 AI 文章生成DeepSeek Flash（成本僅 Pro 的 1/3）
🎮 HTML5 遊戲64 款互動遊戲
🎬 影音自動化產線文章 → NotebookLM → YouTube Shorts
🖼️ AI 配圖生成Pollinations AI（免費、免 API Key）
⚙️ 自動化部署一鍵完成生成 → 輸出 → Cloudflare 部署
☁️ 雲端備份Rclone 自動同步至 Google Drive

13. 常見問題排錯

問題解決方法
Pollinations 配圖生成失敗 檢查網路連線，確認端點可用 image.pollinations.ai/prompt/
文章標題為空或含 HTML 標籤 更新 html_builder.py 至 v5.1 以上
MASTER 顯示「所有文章已存在」 確認 data/pending-articles.json 有內容
圖片變形 確認使用 v7.6 以上的 article_generator.py
