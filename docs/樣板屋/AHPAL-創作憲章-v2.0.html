📜 憲章宣言

AHPAL 歷史腦洞系列致力於以 現代職場、科技與管理學視角， 幽默且深度地解構歷史與宗教故事。
誠實守信，是文明社會永恆的基石。

🎯 核心使命：用跨界思維創造高品質原創內容，讓讀者在趣味中學到現代知識。

🌟 三大核心優勢

🧠
高原創性
跨界結合古代歷史 × 現代職場/科技，每篇必有 SWOT、KPI、戰略分析。
🕊️
無仇恨言論
客觀解構宗教與歷史，用科學與管理學視角分析。
📈
高附加價值
讀者學到現代職場技能、管理思維與科技知識。
📊 AdSense 審核優勢：「高品質原創」、「文化與歷史討論」、「職場與科技觀點」

🛡️ 避坑原則

原則說明實踐方式
⚠️ 點到即止血腥暴力描寫用「戰略分析」視角，不描寫具體細節
📝 結構完整內文厚度每篇 ≥ 3000 字，H1/H2/H3 完整

🔴 紅線：絕對禁止煽動仇恨、歧視、極端宗教宣傳、過度血腥暴力細節。

⚙️ 創作流程

  1. 構思主題 — 歷史/宗教故事 + 現代職業/科技
  2. 確認合規 — 檢查是否觸及紅線
  3. 撰寫大綱 — H1/H2/H3 結構
  4. AI 生成 — Responses API + Reasoning
  5. 品質檢查 — ≥ 80/100
  6. 配圖生成 — Pollinations AI
  7. 分類標示 — 📜 歷史腦洞
  8. 發布部署 — Git + Cloudflare

🚫 絕對禁止事項

  • ❌ 煽動仇恨、歧視或貶低特定宗教族群
  • ❌ 過度血腥、暴力細節描寫
  • ❌ 極端宗教宣傳或極端主義言論
  • ❌ 成人內容、賭博、非法藥物
  • ❌ 薄弱的內容（< 2000 字、無結構）
  • ❌ 誤導性標題（Clickbait）
