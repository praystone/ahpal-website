2. 🔧 本地測試 SOP 與問題根源

🚫 避免錯誤的測試方式

❌ 不建議：直接雙擊 index.html（file:// 協定無法正確解析絕對路徑，導致 CSS 載入失敗）

當您雙擊 index.html 時，/style/main.css 會被解釋為 C:/style/main.css，而不是專案內的 C:/Users/User/ahpal-static/style/main.css

✅ 正確的本地測試方式
# 方法 1：使用 Wrangler（推薦，完全模擬 Cloudflare 環境） cd C:\Users\User\ahpal-static npx wrangler pages dev . # 方法 2：使用 Python HTTP 伺服器（輕量快速） cd C:\Users\User\ahpal-static python -m http.server 8000 # 瀏覽器訪問 http://localhost:8000
💡 為什麼直接雙擊會失敗？

靜態網頁中的 / 是給 Web 伺服器用的根目錄。雙擊檔案時瀏覽器使用 file:// 協定，所有絕對路徑（如 /style/main.css）皆失效，會被解釋為 C:/style/main.css。

解決方法：使用 npx wrangler pages dev . 啟動本地伺服器，所有路徑都會正確解析。
