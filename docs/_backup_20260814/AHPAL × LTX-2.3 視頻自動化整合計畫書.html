📋 計畫摘要

本計畫旨在將 LTX-2.3 視頻生成模型 整合至 AHPAL 全媒體自動化產線，實現從「文章 → 音訊 → 視頻」的完整自動化管道。預計 4 週內完成，每月預算 $25-55。

3. 核心模組設計

3.1 調度腳本 video-gen.ps1

功能說明
任務讀取從 JSON 工作佇列讀取待生成任務
平台調用支援 Modal / Lightning AI / Colab 三種後端
成本控制每日/每月配額管理，自動告警
影音合軌自動將音訊與影片合併 (ffmpeg)
日誌記錄完整記錄每次生成的時間、成本、結果

3.1.1 工作佇列 JSON 格式

{ "title": "望春風 Lo-fi 翻唱 音樂影片", "description": "基於公眾領域歌曲《望春風》的 Lo-fi 翻唱版本", "prompt": "A nostalgic 1930s Taiwanese street scene at night...", "audio_file": "audio/望春風-lofi.wav", "duration": 30, "resolution": "720p", "tags": ["music", "lo-fi"], "priority": "high" }

3.2 多模態整合流程

🔄 完整管道

文字/歌詞 → 音訊 (Suno/NotebookLM) → 關鍵畫面 Prompt 拆解 (AI) → LTX-2.3 視頻生成 (Modal) → ffmpeg 影音合成

3.3 Suno + LTX-2.3 音樂影片產線

步驟工具產出
1. 歌詞分析AI (Responses API)3-5 個視覺場景描述
2. 影片片段生成LTX-2.3 (Modal)多個 10 秒影片片段
3. 片段合併 + 音軌ffmpeg完整音樂影片

4. 成本與配額防護

4.1 成本控制規則

規則設定說明
每日生成上限5 部防止意外過度使用
每月生成上限50 部控制月度預算
單影片長度≤ 60 秒避免高成本長影片
預設解析度720p平衡品質與成本
高優先級才用 A100僅 "priority": "high"節省 GPU 資源

4.2 成本估算

平台每分鐘成本每月 50 部 (30秒)
Modal A100~$0.50/分鐘~$25/月
Lightning AI~$0.60/分鐘~$30/月
Colab Pro$0僅供測試
