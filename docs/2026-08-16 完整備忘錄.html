🩸 血淚教訓 — 願後人不再重蹈覆轍

🔴 教訓 1：永遠不要自動修改核心檔案

auto-history-batch.ps1 中的自動修復區塊將 Emoji 替換為亂碼，導致 182 篇文章受影響。
解決： git checkout 恢復 + 批量修復。從此移除所有自動修改核心檔案的邏輯。

🔴 教訓 2：永遠在執行前載入環境變數

$env:SMTP_USER 為空導致郵件發送失敗。
解決： 建立 ahpal-static.ps1 強制載入 .env。

🔴 教訓 3：處理中文 JSON 時，優先使用 Python

PowerShell 寫入中文 JSON 變成亂碼。
解決： 統一使用 Python 的 json.dump() 寫入。

🔴 教訓 4：永遠在批次生成前檢查餘額

一次生成 57 篇文章，餘額歸零。
解決： 建立 check-deepseek-balance.ps1 自動監控。

🔴 教訓 5：死命令不是裝飾品

文章放在根目錄、中文檔名⋯⋯違反死命令 #2、#3。
解決： 嚴格遵守 8 條死命令，建立 preflight-check.ps1。

🔴 教訓 6：連結格式必須正確

https://www.ahpal.com/about%20%20%20https://www.ahpal.com/privacy-policy 導致 404。
解決： 提供任何連結前，先在本地驗證有效。
