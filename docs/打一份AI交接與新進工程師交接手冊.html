1. 系統概述

雅寶社區 · 頂客論壇 (AHPAL.COM) 是一個 AI 驅動的自動化內容平台，結合：

模組說明
🤖 AI 文章生成支援 Google Gemini（尖峰）與 DeepSeek（離峰）雙 API 自動切換
🎮 HTML5 遊戲62 款互動遊戲，免下載即開即玩

⚙️ 自動化部署一鍵完成內容生成 → 靜態檔案輸出 → Cloudflare 部署
☁️ 雲端備份Rclone 自動同步至 Google Drive (ahpalke@gmail.com)

10. 常見問題排錯

❌ MASTER 不生成文章（顯示「所有文章已存在」）

原因

main.py 判斷所有文章都已存在，無待新增文章。

解決方法
  • 確認 data/pending-articles.json 有內容
  • 執行 .\scripts\add-articles.ps1 手動處理
  • 或使用 MASTER v7.2 的自動處理功能

❌ Gemini API 429 Too Many Requests

解決方法
python src/main.py --force deepseek

或在 MASTER 選單按 [D] 強制使用 DeepSeek

❌ Cloudflare Pages 部署失敗（413 Payload Too Large）

原因

單一檔案超過 25 MiB 限制。

解決方法
  • 影音檔案上傳至 YouTube，不存放於 Pages
  • 檢查 videos/ 目錄是否有大型檔案

❌ 死命令檢查失敗

解決方法
.\scripts\preflight-check.ps1 -Fix

自動修復可修復的問題（如檔案過小、缺少品牌名稱等）。

❌ 含 API 錯誤文章

原因

文章內容包含 429、503、RESOURCE_EXHAUSTED 等錯誤字串。

解決方法
# 找出含 API 錯誤的文章 findstr /s /i /m "429 503 RESOURCE_EXHAUSTED" *.html # 刪除後重新生成 Remove-Item "分類/檔案名稱.html" python src/main.py --force deepseek
