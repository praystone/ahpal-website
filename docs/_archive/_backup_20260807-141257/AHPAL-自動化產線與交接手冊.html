📜 董事長死命令：文章檔名強制使用英文

生效日期：2026 年 8 月 8 日 ｜ 適用範圍：所有新增文章

🔴 死命令內容

自即日起，所有新增文章的檔名（filename）必須為英文（含數字、中線），不得包含中文或其他非 ASCII 字元。

違者視同違反營運紀律，需立即修正。

📋 強制規範

  • 正確範例：worker-blues-original-song.html
  • 錯誤範例：打工人心酸語錄.html（含中文）
  • 自動轉換：meme-to-song.ps1 已內建強制英文轉換邏輯

🚀 強制執行指令

# 檢查是否有中文檔名 Get-ChildItem -Recurse -Filter "*.html" | Where-Object { $_.Name -match '[\u4e00-\u9fa5]' } # 手動重新命名 Move-Item "music\打工人心酸語錄.html" "music\worker-blues-original-song.html"

⚠️ 不咎既往

2026 年 8 月 8 日之前已生成的檔案（如 music/打工人心酸語錄.html）維持原樣，不予追究。

⚠️ 此命令已錄入紅皮書，作為永久性強制規範。違者視同違反營運紀律。

1. 🎬 影音自動化產線

🎯 已打通！文章 → 音訊 → YouTube 全自動化

AHPAL 的文章現在可以自動轉換為 YouTube Shorts 影音內容。

1.1 產線流程圖

📄 AHPAL 文章 → 🔄 youtube-pipeline.ps1 → 🎧 音訊播客
│
├─ notebooklm use → 設定 Notebook 上下文
├─ source add → 新增文章內容
├─ generate audio → 觸發 AI 生成
├─ artifact wait → 等待任務完成
└─ download audio → 下載音訊檔案
│
☁️ Cloudflare Pages → 🌐 https://www.ahpal.com/audio/
🎬 YouTube → 📺 AHPAL 頻道

1.2 執行影音產線

# 完整產線（文章 → 音訊 → YouTube） .\scripts\youtube-pipeline.ps1 -ArticlePath "tech\文章.html" .\scripts\youtube-upload-realtime.ps1 -VideoFile "audio\podcast.wav" -Title "標題" # 批次上傳（流量管制，每日上限 85 支） .\scripts\batch-upload-throttled.ps1

1.3 技術亮點

技術說明
NotebookLMGoogle 筆記本 AI，文章轉音訊
OAuth 2.0YouTube 安全上傳授權
流量管制每日上限 85 支 Shorts，避免 API 配額超限
二進位安全上傳ReadAllBytes 確保 100% 檔案完整性
📌 重要決策
  • 影音檔案不存放於 Cloudflare Pages（單一檔案限制 25 MiB）
  • 統一存放於 YouTube 與 AI 檔案館

2. ⭐ 新增文章（JSON 驅動）

🎯 核心生產力工具

你不需要手動編輯 main.py！只要編輯 JSON，執行腳本，AI 就會為你生成文章。

🔴 強制規範

filename 必須為英文（參見上方董事長死命令）。

步驟 1：編輯 data/pending-articles.json

[ { "keyword": "2026 年最新 AI 工具推薦", "category": "🤖 AI 趨勢", "filename": "trend/ai-tools-2026.html", // ⚠️ 必須為英文 "use_responses_api": true, "enable_reasoning": true, "enable_search": false }, { "keyword": "居家收納終極指南：小空間變大秘訣", "category": "🏠 生活小常識", "filename": "life/home-organization-guide-2026.html", // ⚠️ 必須為英文 "use_responses_api": true, "enable_reasoning": true, "enable_search": false } ]

步驟 2：執行轉換腳本

cd C:\Users\User\ahpal-static .\scripts\add-articles.ps1 -Force

步驟 3：執行文章生成

python src/main.py --force deepseek # 或使用萬能總指揮 .\scripts\ahpal-master.ps1 → [1]

3. 🎵 迷因轉歌曲（meme-to-song.ps1）

🎯 一鍵迷因轉歌曲文章

將 PTT/Dcard/時事迷因自動轉為音樂文章 + Suno 歌曲。

🔴 強制規範

檔名自動轉為英文（符合董事長死命令）。

3.1 使用方式

# 預覽模式（僅顯示將要執行的操作） .\scripts\meme-to-song.ps1 -Meme "打工人心酸語錄" -Source "PTT" -DryRun # 正式執行（生成文章 + 自動部署） .\scripts\meme-to-song.ps1 -Meme "打工人心酸語錄" -Source "PTT" -Force # 包含 Suno 音訊生成（需設定 SUNO_API_KEY） .\scripts\meme-to-song.ps1 -Meme "打工人心酸語錄" -Source "PTT" -GenerateAudio -Force

3.2 自動化流程

步驟說明
1輸入迷因主題與來源
2自動產生英文檔名
3寫入 JSON 待產清單
4自動生成音樂文章（Responses API + Reasoning）
5更新 main.py 與清空 JSON

3.3 檔名轉換範例

輸入（中文）輸出（英文）
打工人心酸語錄worker-blues-original-song.html
颱風假廢文typhoon-day-off-meme.html
AI 取代人類ai-replace-humans.html

🎵 音樂文章專用

自動嵌入 YouTube 影片，含歌詞解析、台羅拼音。

🔴 強制規範

filename 必須為英文（參見董事長死命令）。

步驟 1：編輯 data/pending-songs.json

[ { "keyword": "望春風 Lo-fi 翻唱 歌詞 台羅拼音 解析", "category": "🎵 音樂創作", "filename": "music/bang-chhun-hong.html", // ⚠️ 必須為英文 "video_id": "A9Zw-QHEOqQ", "content_type": "song" } ]

步驟 2：執行轉換腳本

cd C:\Users\User\ahpal-static .\scripts\add-articles.ps1 -Force

步驟 3：執行文章生成

python src/main.py --force deepseek
🎬 YouTube 自動嵌入
  • JSON 驅動：在 pending-songs.json 中填入 video_id
  • 自動嵌入：song_generator.py 自動生成 YouTube iframe
  • 置頂顯示：影片顯示在文章開頭（黃金 Header 下方）
  • 響應式設計：16:9 比例，適應所有裝置

7. 常見問題排錯

❌ Gemini API 429 Too Many Requests

解決方法
python src/main.py --force deepseek

❌ Cloudflare Pages 部署失敗（413 Payload Too Large）

原因

單一檔案超過 25 MiB 限制。

解決方法
  • 影音檔案上傳至 YouTube，不存放於 Pages
  • 檢查 videos/ 目錄是否有大型檔案

❌ Google Drive 備份失敗

解決方法
.\scripts\sync-to-gdrive.ps1 -Task videos

使用 Rclone 統一同步工具，繞過虛擬磁碟限制。

❌ 死命令檢查失敗

解決方法
.\scripts\preflight-check.ps1 -Fix

自動修復可修復的問題（如檔案過小、缺少品牌名稱等）。

❌ Pollinations 配圖生成失敗

解決方法
  • 檢查網路連線
  • 確認端點可用：image.pollinations.ai/prompt/

❌ Git 推送失敗（rejected）

解決方法
git pull --rebase git push
