13. 🆕 標準化分類新增 SOP 🆕 v4.4 新增

📌 背景： AHPAL 在 2026-08-16 ~ 2026-08-17 期間新增「🌳 動植物生態」分類時，因未遵循標準化流程，經歷了多次陣痛（檔案重複、main.py 判斷錯誤、排程 PIN 碼問題）。
本 SOP 旨在確保未來新增任何分類時，不再重蹈覆轍。

13.1 新增分類標準流程

步驟 1
📂 建立目錄
mkdir C:\Users\User\ahpal-static\新分類名稱
步驟 2
🐍 更新 config.py
新增分類到 CATEGORIES 與 CATEGORY_EMOJI_MAP
步驟 3
🐍 更新 main.py
新增映射到 CATEGORY_DIR_MAP 與 CATEGORY_EMOJI_MAP
步驟 4
🐍 更新 html_builder.py
新增映射到 CATEGORY_EMOJI_MAP
步驟 5
🖥️ 更新 ahpal-master.ps1
新增分類到 $categories 哈希表
步驟 6
🖥️ 更新 check-all.ps1
新增目錄到 $CategoryDirs 與 $CategoryPages
步驟 7
🖥️ 更新 preflight-check.ps1
新增目錄到 $ArticleDirs 與 $Categories
步驟 8
📝 建立批次腳本
基於 auto-nature-batch.ps1 v2.0 改造
步驟 9
⏰ 建立排程
使用 SYSTEM 帳戶 (ServiceAccount)
步驟 10
✅ 驗證
執行 check-all.ps1 -Report 確認

13.2 批次腳本範本 (v2.0 架構)

# ============================================================ # 📝 新分類批次腳本範本 (基於 auto-nature-batch.ps1 v2.0) # ============================================================ # 🆕 核心差異：不依賴 main.py 的判斷邏輯 # 🆕 直接呼叫 article_generator.generate_article() python -c " import json import sys import os sys.path.insert(0, '.') from src.article_generator import generate_article # 1. 讀取 master-articles.json with open('data/master-articles.json', 'r', encoding='utf-8') as f: all_articles = json.load(f) # 2. 過濾目標分類文章 target_articles = [ a for a in all_articles if a.get('filename', '').startswith('target/') ] print(f'📊 找到 {len(target_articles)} 篇目標文章') # 3. 逐一檢查並生成 success = 0 for idx, article in enumerate(target_articles, 1): filepath = f'./{article["filename"]}' # 檢查檔案是否存在且有效 if os.path.exists(filepath) and os.path.getsize(filepath) >= 5120: print(f'⏩ [{idx}/{len(target_articles)}] 已存在') continue print(f'--- 進度 {idx}/{len(target_articles)} ---') try: generate_article(article) success += 1 except Exception as e: print(f'❌ 失敗：{e}') print(f'✅ 成功生成 {success} 篇') "

13.3 修改清單對照表

檔案修改內容範例
src/config.py新增分類到 CATEGORIES"nature": {"name": "🌳 動植物生態", ...}
src/main.py新增 CATEGORY_DIR_MAP"🌳 動植物生態": "nature"
src/html_builder.py新增 CATEGORY_EMOJI_MAP"🌳": "🌳 動植物生態"
scripts/ahpal-master.ps1新增 $categories"nature" = "🌳 動植物生態"
scripts/check-all.ps1新增 $CategoryDirs"nature" = "🌳 動植物生態"
scripts/preflight-check.ps1新增 $ArticleDirs"nature"
✅ 核心原則：
1. 永遠不依賴 main.py 的判斷邏輯 — 直接呼叫 article_generator
2. 永遠使用 SYSTEM 帳戶排程 — 無需 PIN 碼
3. 永遠先掃描目錄 — 確認缺失數量後再執行
