1. 系統概述

雅寶社區 · 頂客論壇 (AHPAL.COM) 是一個 AI 驅動的自動化內容平台，結合：

模組說明
🤖 AI 文章生成支援 Google Gemini（尖峰）與 DeepSeek（離峰）雙 API 自動切換
🎮 HTML5 遊戲54 款互動遊戲，免下載即開即玩
⚙️ 自動化部署一鍵完成內容生成 → 靜態檔案輸出 → Cloudflare 部署

1.1 系統數據（截至 2026.07.25）

指標數值
總文章數345 篇
遊戲數量54 款
分類數量6 大類
Sitemap URL 數352 個
✅ 系統核心優勢
  • JSON 驅動新增文章：編輯 JSON 即可批次新增文章，無需手動改程式碼
  • 雙 API 備援：尖峰 Gemini / 離峰 DeepSeek 自動切換
  • 品質保證：自動檢查字數、標題結構，品質分數 ≥ 80 分才發布
  • 斷點續傳：透過 article-manifest.json 記錄狀態，中斷後可續傳

5. ⭐ 新增文章（JSON 驅動）

🎯 這是 AHPAL 內容營運的核心生產力工具

你不需要手動編輯 main.py！只要編輯 JSON，執行腳本，AI 就會為你生成文章。

步驟 1：編輯 data/pending-articles.json

[ { "keyword": "2026 年最新 AI 工具推薦", "category": "🤖 AI 趨勢" }, { "keyword": "居家收納終極指南：小空間變大秘訣", "category": "🏠 生活小常識" }, { "keyword": "2026 旗艦手機拍照評測", "category": "💻 3C 科技教學" } ]
分類（category）對應目錄
💻 3C 科技教學tech/
🎮 遊戲攻略game/
🏠 生活小常識life/
📊 軟體評測review/
🌟 人生哲理philosophy/
🤖 AI 趨勢trend/

步驟 2：執行轉換腳本

cd C:\Users\User\ahpal-static .\scripts\add-articles.ps1

步驟 3：執行文章生成

python src/main.py --force deepseek
📌 完整流程 編輯 JSON → 執行 add-articles.ps1 → python src/main.py --force deepseek

✅ 不需要手動編輯 main.py！JSON 驅動，安全又快速。

8. 常見問題排錯

❌ DeepSeek API 400 Bad Request

原因

DeepSeek 模型名稱過時。目前支援 deepseek-v4-pro 或 deepseek-v4-flash。

解決方法
cd C:\Users\User\ahpal-static # 檢查 config.py 中的 DEEPSEEK_MODEL notepad src\config.py # 確認: DEEPSEEK_MODEL = "deepseek-v4-pro"

❌ .env 檔案不存在

解決方法
cd C:\Users\User\ahpal-static Copy-Item .env.template .env notepad .env # 填入實際 API Key

❌ 文章品質 0 分（字數不足）

解決方法
.\scripts\check-articles.ps1 .\scripts\check-articles.ps1 -Fix
