喚醒定時器測試標準作業程序
📌 版本 v1.0 · 2026 年 8 月 16 日
✅ 董事會核定 · 全員遵行

1. 目的

確保 AHPAL 系統在 螢幕關閉／系統睡眠 狀態下，工作排程器仍能 100% 準時喚醒 CPU 並執行預定任務，避免因 Windows Modern Standby (S0 低功耗閒置) 導致排程延遲或遺漏。

2. 適用情境

情境說明
🌙 晚間 19:00 歷史腦洞批次生成每日固定生成 100 篇文章
💾 凌晨備份任務每日凌晨自動備份系統
☁️ Cloudflare 部署任務生成完成後自動部署
⚙️ 任何無人值守排程需長時間關閉螢幕但須準時執行

3. 前置條件

項目條件
🖥️ 作業系統Windows 11 (22H2 以上)
🔑 權限系統管理員權限
🔌 電源建議插上 AC 電源 (確保喚醒定時器正常運作)
🔧 BIOS確認 BIOS 中 Wake on RTC / Wake on USB 已啟用

4. 標準作業步驟

步驟 1：開啟喚醒定時器 (一次性設定)

以系統管理員身分執行 PowerShell，開啟系統喚醒定時器：

# ============================================================ # 步驟 1：開啟喚醒定時器 # ============================================================ # 1.1 開啟插電 (AC) 狀態下的喚醒定時器 powercfg -setacvalueindex SCHEME_CURRENT 238c9fa8-0aad-41ed-83f4-97be242c8f20 bd3b718a-0680-4d9d-8ab2-e1d2b4ac806d 1 # 1.2 開啟電池 (DC) 狀態下的喚醒定時器 powercfg -setdcvalueindex SCHEME_CURRENT 238c9fa8-0aad-41ed-83f4-97be242c8f20 bd3b718a-0680-4d9d-8ab2-e1d2b4ac806d 1 # 1.3 套用目前電源計畫 powercfg -setactive SCHEME_CURRENT Write-Host "✅ 喚醒定時器已開啟" -ForegroundColor Green

步驟 2：註冊可喚醒排程任務

# ============================================================ # 步驟 2：註冊可喚醒排程任務 # ============================================================ param( [string]$TaskName = "AHPAL_Scheduled_Task", [string]$ScriptPath = "C:\Users\User\ahpal-static\scripts\target-script.ps1", [datetime]$ExecutionTime = (Get-Date).AddMinutes(5) ) # 2.1 定義任務動作 $Action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoProfile -ExecutionPolicy Bypass -WindowStyle Normal -File `"$ScriptPath`"" # 2.2 定義觸發時間 $Trigger = New-ScheduledTaskTrigger -Once -At $ExecutionTime # 2.3 定義執行權限 (互動模式，可顯示視窗) $Principal = New-ScheduledTaskPrincipal -UserId "$env:COMPUTERNAME\$env:USERNAME" -RunLevel Highest -LogonType Interactive # 2.4 定義任務設定 (關鍵：WakeToRun + Priority 4) $Settings = New-ScheduledTaskSettingsSet ` -AllowStartIfOnBatteries ` -WakeToRun ` -DontStopIfGoingOnBatteries ` -StartWhenAvailable ` -Priority 4 ` -ExecutionTimeLimit (New-TimeSpan -Hours 4) # 2.5 註冊任務 Register-ScheduledTask -TaskName $TaskName -Action $Action -Trigger $Trigger -Principal $Principal -Settings $Settings -Force Enable-ScheduledTask -TaskName $TaskName Write-Host "✅ 任務已註冊並啟用，執行時間：$ExecutionTime" -ForegroundColor Green

步驟 3：驗證喚醒計時器

# ============================================================ # 步驟 3：驗證喚醒計時器是否正常掛載 # ============================================================ # 3.1 顯示所有喚醒計時器 powercfg /waketimers # 3.2 檢查任務狀態 Get-ScheduledTask -TaskName $TaskName | Format-List TaskName, State, Triggers
✅ 預期輸出範例：
[SERVICE] ... 設定的計時器在 HH:mm:ss 到期。
原因: Windows 將執行 'NT TASK\AHPAL_Scheduled_Task' 排定要求喚醒電腦的工作。

步驟 4：觸發睡眠測試

# ============================================================ # 步驟 4：觸發睡眠 (使用 C# 原生 API，確保喚醒計時器不受干擾) # ============================================================ # 4.1 關閉螢幕 (系統保持運作) $code = @" using System; using System.Runtime.InteropServices; public class Screen { [DllImport("user32.dll")] public static extern int SendMessage(int hWnd, int hMsg, int wParam, int lParam); } "@ Add-Type -TypeDefinition $code [Screen]::SendMessage(0xffff, 0x0112, 0xF170, 2) # 4.2 觸發睡眠 (不強制關閉，不禁用喚醒事件) $sleepCode = @" using System; using System.Runtime.InteropServices; public class Power { [DllImport("Powrprof.dll", SetLastError = true)] public static extern bool SetSuspendState(bool hibernate, bool forceCritical, bool disableWakeEvent); } "@ Add-Type -TypeDefinition $sleepCode [Power]::SetSuspendState($false, $false, $false) Write-Host "✅ 系統已進入睡眠，喚醒計時器將於指定時間觸發" -ForegroundColor Green

6. 疑難排解

問題可能原因解決方法
喚醒計時器未掛載 電源計畫未啟用 重複執行步驟 1
排程延遲執行 Modern Standby 介入 確保 -WakeToRun 與 Priority 4 已設定
無 PowerShell 視窗 LogonType 為 S4U 改用 Interactive
任務未執行 權限不足 確保 -RunLevel Highest
