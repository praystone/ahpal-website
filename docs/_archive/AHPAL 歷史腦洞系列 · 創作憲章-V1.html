📜 憲章宣言

AHPAL 歷史腦洞系列致力於以 現代職場、科技與管理學視角， 幽默且深度地解構歷史與宗教故事。 我們相信：誠實守信，是文明社會永恆的基石。

🎯 核心使命： 用跨界思維創造高品質原創內容，讓讀者在趣味中學到現代知識。

🌟 三大核心優勢

🧠
高原創性
跨界結合古代歷史 × 現代職場/科技/管理學，每篇必有 SWOT、KPI、戰略分析等深度觀點。
🕊️
無仇恨言論
客觀解構宗教與歷史故事，用科學與管理學視角分析，絕不煽動仇恨或歧視。
📈
高附加價值
讀者不僅讀到有趣故事，還能學到現代職場技能、管理思維與科技知識。
📊 AdSense 審核優勢： 此類內容被歸類為「高品質原創」、「文化與歷史討論」、「職場與科技觀點」， AI 審核系統通常給予高度評價。

🛡️ 避坑原則 (嚴格遵守)

原則說明實踐方式
⚠️ 點到即止 血腥暴力描寫 戰爭/處決場景用「戰略分析」視角，不描寫具體細節
📝 結構完整 內文厚度 每篇 ≥ 3000 字，包含 H1/H2/H3 完整結構
🏷️ 明確分類 網站定位 標示「📜 歷史腦洞」+ 頁面說明「幽默創意/歷史解構」
✅ 合規主題 主題選擇 圍繞歷史、職涯、科技，避開成人、暴力、賭博、非法藥物
🔴 紅線： 絕對禁止煽動仇恨、歧視、極端宗教宣傳、過度血腥暴力細節。

📋 文章結構標準

元素要求範例
標題 吸睛 + 明確主題 「如果現代 PM 穿越到巴別塔⋯⋯」
H1 標題 1 個，完整主題 與文章標題一致
H2 標題 ≥ 3 個 背景、分析、結論
H3 標題 ≥ 2 個 細分觀點
字數 ≥ 3000 字 深度分析，不灌水
配圖 ≥ 1 張 Pollinations AI 生成
結構元素 表格 / FAQ / 清單 至少包含 2 種
✅ 品質門檻： 每篇文章品質分數須 ≥ 80/100，否則重新生成或手動修訂。

⚙️ 創作流程

  1. 構思主題 — 選擇歷史/宗教故事 + 現代職業/科技
  2. 確認合規 — 檢查是否觸及紅線（仇恨/暴力/極端）
  3. 撰寫大綱 — H1/H2/H3 結構 + 核心觀點
  4. AI 生成 — 使用 Responses API + Reasoning
  5. 品質檢查 — 確保 ≥ 80/100
  6. 配圖生成 — Pollinations AI
  7. 分類標示 — 📜 歷史腦洞
  8. 發布部署 — Git + Cloudflare Pages
📌 注意： 所有文章生成後須通過 preflight-check.ps1 死命令檢查才能部署。

🚫 絕對禁止事項

  • ❌ 煽動仇恨、歧視或貶低特定宗教族群
  • ❌ 過度血腥、暴力細節描寫（Shocking Content）
  • ❌ 極端宗教宣傳或極端主義言論
  • ❌ 成人內容、賭博、非法藥物
  • ❌ 薄弱的內容（< 2000 字、無結構）
  • ❌ 誤導性標題（Clickbait）
  • ❌ 抄襲或複製貼上
🔴 違反後果： 違反上述事項將導致文章下架、AdSense 帳戶風險，並視同違反董事長死命令。
