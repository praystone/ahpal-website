11. 🔋 系統層級 RTC 喚醒 SOP 🆕 v4.2 新增

📌 問題背景： Windows 11 預設電源計劃會封鎖第三方排程的喚醒請求，導致排程任務無法在指定時間自動喚醒系統。

11.1 終極修復 SOP (一次性設定)

步驟 1：解鎖 RTC 喚醒定時器

# 強制在 AC (插電) 狀態下開啟系統喚醒定時器 powercfg /SETACVALUEINDEX SCHEME_CURRENT SUB_SLEEP RTCWAKE 1 powercfg /SETACTIVE SCHEME_CURRENT

步驟 2：建立含喚醒設定的排程任務

$Action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-ExecutionPolicy Bypass -File `"C:\Users\User\ahpal-static\scripts\auto-life-batch.ps1`"" $Trigger = New-ScheduledTaskTrigger -Once -At (Get-Date).AddMinutes(5) $Settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -WakeToRun $Principal = New-ScheduledTaskPrincipal -UserId "$env:COMPUTERNAME\$env:USERNAME" -LogonType Interactive -RunLevel Highest Register-ScheduledTask -TaskName "AHPAL_Batch" -Action $Action -Trigger $Trigger -Settings $Settings -Principal $Principal -Force

步驟 3：驗證喚醒設定

# 檢查系統是否已成功排入 RTC 喚醒警報 powercfg /waketimers

11.2 關鍵參數說明

參數說明
RTCWAKE 1啟用即時時鐘喚醒 (AC 電源)
-WakeToRun排程任務可喚醒系統執行
-AllowStartIfOnBatteries電池模式下允許執行
-DontStopIfGoingOnBatteries切換電池時不中斷
powercfg /waketimers診斷指令，列出所有喚醒計時器
✅ 驗證通過標準： 執行 powercfg /waketimers 後，若輸出中能看到排程任務名稱及其預定執行時間，即代表硬體喚醒已完全就緒。

12. 📋 排程測試驗證清單 🆕 v4.3 新增

📌 目的： 建立排程任務後，依此清單逐項驗證，確保排程、喚醒、生成、部署全鏈路正常運作。

12.1 驗證項目清單

#檢查項目驗證指令成功標準
1 RTC 喚醒已註冊 powercfg /waketimers 輸出中包含排程任務名稱
2 排程任務狀態 Get-ScheduledTask -TaskName "AHPAL_LifeBatch" State = "Ready"
3 排程觸發時間 (Get-ScheduledTask -TaskName "AHPAL_LifeBatch").Triggers.StartBoundary 顯示正確的執行時間
4 腳本路徑正確 Test-Path "C:\Users\User\ahpal-static\scripts\auto-life-batch.ps1" 回傳 True
5 日誌檔案產生 Test-Path "C:\Users\User\ahpal-static\logs\auto-life-batch-*.log" 執行後產生 .log 檔案
6 API Key 已載入 檢查日誌中是否有 ✅ DEEPSEEK_API_KEY 已從 .env 載入 出現於日誌中
7 文章合併成功 檢查日誌中是否有 ✅ 文章合併完成 出現於日誌中
8 文章生成成功 檢查日誌中是否有 ✅ 文章生成完成 出現於日誌中
9 分類頁面更新 檢查日誌中是否有 ✅ 分類頁面與首頁已更新 出現於日誌中
10 部署成功 檢查日誌中是否有 ✅ 部署完成 出現於日誌中

12.2 完整驗證腳本

📌 使用方式： 複製下方腳本，在 PowerShell 中執行，自動檢查所有項目。
# ============================================================ # 🔍 AHPAL 排程驗證腳本 v1.0 # ============================================================ Write-Host "============================================================" -ForegroundColor Cyan Write-Host " 🔍 AHPAL 排程驗證工具 v1.0" -ForegroundColor Cyan Write-Host "============================================================" -ForegroundColor Cyan Write-Host "" $TaskName = "AHPAL_LifeBatch" $ScriptPath = "C:\Users\User\ahpal-static\scripts\auto-life-batch.ps1" $LogDir = "C:\Users\User\ahpal-static\logs" $PassCount = 0 $FailCount = 0 # 1. 檢查 RTC 喚醒 Write-Host "[1] RTC 喚醒狀態:" -ForegroundColor Yellow $wake = powercfg /waketimers | Select-String $TaskName if ($wake) { Write-Host " ✅ 已註冊" -ForegroundColor Green $PassCount++ } else { Write-Host " ❌ 未註冊" -ForegroundColor Red $FailCount++ } # 2. 檢查排程狀態 Write-Host "[2] 排程任務狀態:" -ForegroundColor Yellow $task = Get-ScheduledTask -TaskName $TaskName -ErrorAction SilentlyContinue if ($task -and $task.State -eq "Ready") { Write-Host " ✅ State: $($task.State)" -ForegroundColor Green $PassCount++ } elseif ($task) { Write-Host " ⚠️ State: $($task.State) (非 Ready)" -ForegroundColor Yellow $FailCount++ } else { Write-Host " ❌ 任務不存在" -ForegroundColor Red $FailCount++ } # 3. 檢查觸發時間 Write-Host "[3] 排程觸發時間:" -ForegroundColor Yellow if ($task -and $task.Triggers) { $trigger = $task.Triggers[0] if ($trigger.StartBoundary) { Write-Host " ✅ $($trigger.StartBoundary)" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 無觸發時間" -ForegroundColor Yellow $FailCount++ } } else { Write-Host " ❌ 無法讀取觸發時間" -ForegroundColor Red $FailCount++ } # 4. 檢查腳本存在 Write-Host "[4] 腳本存在:" -ForegroundColor Yellow if (Test-Path $ScriptPath) { Write-Host " ✅ 存在" -ForegroundColor Green $PassCount++ } else { Write-Host " ❌ 不存在" -ForegroundColor Red $FailCount++ } # 5. 檢查最新日誌 Write-Host "[5] 最新日誌:" -ForegroundColor Yellow $logs = Get-ChildItem "$LogDir\auto-life-batch-*.log" -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending if ($logs) { $latest = $logs[0] Write-Host " ✅ $($latest.Name) ($($latest.LastWriteTime))" -ForegroundColor Green $PassCount++ $content = Get-Content $latest -Raw # 檢查 API Key Write-Host "[6] API Key 已載入:" -ForegroundColor Yellow if ($content -match "✅ DEEPSEEK_API_KEY 已從 .env 載入") { Write-Host " ✅ 已載入" -ForegroundColor Green $PassCount++ } else { Write-Host " ❌ 未載入" -ForegroundColor Red $FailCount++ } # 檢查文章合併 Write-Host "[7] 文章合併成功:" -ForegroundColor Yellow if ($content -match "✅ 文章合併完成") { Write-Host " ✅ 成功" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 尚未合併" -ForegroundColor Yellow $FailCount++ } # 檢查文章生成 Write-Host "[8] 文章生成成功:" -ForegroundColor Yellow if ($content -match "✅ 文章生成完成") { Write-Host " ✅ 成功" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 尚未完成生成" -ForegroundColor Yellow $FailCount++ } # 檢查分類頁面更新 Write-Host "[9] 分類頁面更新:" -ForegroundColor Yellow if ($content -match "✅ 分類頁面與首頁已更新") { Write-Host " ✅ 已更新" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 尚未更新" -ForegroundColor Yellow $FailCount++ } # 檢查部署 Write-Host "[10] 部署成功:" -ForegroundColor Yellow if ($content -match "✅ 部署完成") { Write-Host " ✅ 成功" -ForegroundColor Green $PassCount++ } else { Write-Host " ⚠️ 尚未部署" -ForegroundColor Yellow $FailCount++ } } else { Write-Host " ❌ 無日誌檔案" -ForegroundColor Red $FailCount++ } Write-Host "" Write-Host "============================================================" -ForegroundColor Cyan Write-Host " 📊 驗證結果：" -ForegroundColor Yellow Write-Host " ✅ 通過：$PassCount 項" -ForegroundColor Green Write-Host " ❌ 失敗：$FailCount 項" -ForegroundColor Red if ($FailCount -eq 0) { Write-Host " 🎉 全部通過！排程運作正常！" -ForegroundColor Green } else { Write-Host " ⚠️ 請檢查失敗項目並重新執行" -ForegroundColor Yellow } Write-Host "============================================================" -ForegroundColor Cyan

12.3 常見喚醒失敗排查

問題可能原因解決方案
排程未執行 RTC 喚醒未啟用 powercfg /SETACVALUEINDEX SCHEME_CURRENT SUB_SLEEP RTCWAKE 1
排程未執行 BIOS 喚醒未啟用 進入 BIOS → Power Management → Wake on RTC / Resume by Alarm → 啟用
排程延遲 5+ 分鐘 系統從深度睡眠喚醒時間較長 將排程時間提前 5-10 分鐘（SOP 標準）
任務狀態為 Disabled 任務被手動停用 Enable-ScheduledTask -TaskName "AHPAL_LifeBatch"
powercfg /waketimers 無輸出 排程未設定 -WakeToRun 重新建立任務，加入 -WakeToRun 參數
